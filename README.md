# Linux, Networking & Cloud Infrastructure Lab

## Objective

This project demonstrates basic Linux administration,
networking concepts, SSH access, cloud infrastructure,
firewall configuration, and Nginx deployment on AWS EC2.

## Technologies Used

- Linux
- Ubuntu
- AWS EC2
- AWS Security Groups
- SSH
- Nginx
- UFW
- Git
- GitHub

## Architecture

Internet
   |
   | HTTP :80
   ↓
AWS Security Group
   |
   ↓
Ubuntu EC2
   |
   ↓
Nginx
   |
   ↓
Web Application

## Tasks Completed

- Linux CLI operations
- Users and groups
- File permissions
- Process management
- Service management
- SSH configuration
- IP addressing
- DNS
- Ports
- Firewall
- AWS EC2
- Security Group
- Nginx deployment
- Connectivity testing

## Result

Successfully deployed an Nginx web server on an
Ubuntu EC2 instance and accessed it through the
server's public IP address.
